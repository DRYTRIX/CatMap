CatMap — an anonymous world map of cat sightings

CatMap is a free, anonymous world map for cat sightings. Drop a pin anywhere with a photo to report a cat, and help other people confirm sightings in their own neighborhood — no account or sign-up required.

How it works

  1. Drop a pin — Tap the map where you spotted a cat.
  2. Add a photo — Attach a picture so others can recognize the cat.
  3. Confirm sightings — Anyone can confirm a cat is still around, keeping the map up to date.
  4. No account needed — Posting and confirming work anonymously with a private, on-device token. Create an account only if you want to sync across devices.
